This product is a ChatGPT-style novel writing assistant.

The primary goal is to support writers in drafting, revising, and managing long-form narrative content with minimal cognitive friction. The product should feel calm, focused, and trustworthy.

## Product Priorities

1. Writing flow is sacred. The UI must not interrupt creative momentum.
2. Readability and clarity are more important than visual flair.
3. Revision should feel safe, reversible, and non-destructive.
4. The system should help users remember context without overwhelming them.

## Core UX Concepts

- A scrolling chat interface similar to ChatGPT.
- Clear separation between user input and assistant output.
- Revision controls attached only to assistant messages.
- A memory or summary sidebar that surfaces recent context succinctly.

## Design Constraints

- The interface should be usable for long writing sessions.
- Avoid visual noise, animations, or UI elements that compete with the text.
- Mobile usability matters, but desktop is the primary use case.

## Product Philosophy

- This is a tool, not a social app.
- Speed and responsiveness matter, but not at the cost of correctness.
- Features should be added only if they clearly support writing.

## Non-Goals

- This is not a general-purpose chat application.
- This is not a design showcase.
- This is not optimized for virality or engagement metrics.
