# CANON REAL-WORLD & PROXY CHARACTER

Dokumen ini mengatur bagaimana unsur dunia nyata masuk ke cerita fiksi
tanpa menjadikan cerita glorifikasi figur publik,
tanpa menggunakan nama asli,
dan tanpa menggeser pusat narasi dari Handy & keluarganya.

Dokumen ini BERSIFAT MENGIKAT.
Agent WAJIB mematuhinya.

---

## 1) PRINSIP UTAMA (KERAS)

1. Cerita ini fiksi. Dunia nyata hanya PEMANTIK, bukan pusat cerita.
2. Nama figur dunia nyata TIDAK BOLEH muncul di narasi.
3. Semua pengaruh dunia nyata HARUS dimediasi melalui PROXY CHARACTER (karakter fiksi).
4. Jika ada konflik antara “ikon real-world” vs “perjalanan Handy”:
   → PERJALANAN HANDY MENANG.

---

## 2) DEFINISI PROXY CHARACTER

Proxy Character adalah karakter fiksi penuh yang:

- punya nama fiksi, latar fiksi, dan keputusan sendiri
- boleh terinspirasi aura/posisi/energi karier figur nyata (INTERNAL)
- boleh hadir singkat atau panjang (lintas fase boleh)
- boleh gagal, berubah, putus–nyambung relasi, atau menghilang

Proxy Character TIDAK BOLEH:

- selalu benar / selalu menang
- jadi “penyelamat”
- jadi pusat makna hidup Handy
- membuat cerita berubah jadi biografi figur inspirasi

---

## 3) MODE OTOMASI (DENGAN KONTROL)

Ada 2 mode:

### A. MODE "REGISTERED" (DIREKOMENDASIKAN)

Proxy boleh dipakai jika sudah ada di:

- `proxy-registry.md`

### B. MODE "PROPOSED" (OTOMATIS TAPI AMAN)

Agent BOLEH mengusulkan proxy baru saat menulis bab,
TAPI proxy itu statusnya "PROPOSED" dan:

- tidak boleh jadi tokoh penting
- tidak boleh membawa plot besar
- hanya boleh muncul sebagai "bayangan" (1 adegan / 1 fungsi kecil)
- harus ditulis sangat minimal, manusiawi, tanpa aura ikonik

Lalu agent WAJIB menulis catatan di akhir `prompts/chapter-(n).md`:

- Proposed: [KODE_PROXY] → proxy-registry.md (butuh approval penulis)

Tanpa approval penulis:
→ agent DILARANG menaikkan peran proxy itu di bab berikutnya.

---

## 4) KATEGORI PENGARUH REAL-WORLD

### A. MENTOR / TAMU

Boleh:

- memberi perspektif singkat
- memantik pikiran
- hadir terbatas (1 sesi / 1 event / 1 kunjungan)

Tidak boleh:

- mengatur arah hidup Handy
- menyelesaikan konflik inti
- jadi “validasi absolut”

### B. PASANGAN / RELASI INTIM

Wajib Proxy Character.
Aturan:

- manusiawi (jatuh cinta, ragu, putus, nyambung lagi boleh)
- proxy punya agenda sendiri
- tidak diposisikan sebagai “hadiah”

### C. REKAN KERJA JANGKA PANJANG (MANAGER / PARTNER)

- tidak harus masuk core
- dicatat sejak fase pertemuan
- boleh lintas fase sangat panjang
- relasi berkembang gradual

---

## 5) ANTI-IDOLIZING RULE (KERAS)

Agent DILARANG:

- bahasa pemujaan ("legenda", "ikon sempurna", "beruntung bertemu idola")
- memposisikan proxy sebagai sosok selalu benar
- membuat Handy bergantung emosional/karier pada proxy

Jika ragu:

- pendekkan adegan
- kurangi dialog
- biarkan dampak bekerja diam-diam

Jika ragu antara "ikonik" vs "manusiawi":
→ PILIH MANUSIAWI.

---

## 6) FORMAT PENULISAN DI NARASI (WAJIB)

- Narasi tidak menyebut "inspirasi real-world".
- Tidak meniru dialog publik figur nyata secara eksplisit.
- Proxy diperkenalkan sesuai `rules.md/style.md`:
  visual dulu → nama belakangan (untuk kemunculan pertama).
- Setelah sudah dikenalkan, penyebutan nama langsung boleh saat tempo cepat.

---

## 7) PENUTUP

Proxy adalah katalis, bukan tujuan.
Cerita tetap milik Handy.
