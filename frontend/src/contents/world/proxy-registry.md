# PROXY REGISTRY (SATU-SATUNYA PINTU MASUK)

Dokumen ini adalah inventaris PROXY CHARACTER yang DIIZINKAN.
Agent hanya boleh membuat atau memakai proxy penting jika TERDAFTAR di sini.

Proxy = karakter fiksi penuh yang boleh “terasa” terinspirasi figur nyata,
tetapi cerita DILARANG menyatakan inspirasinya.

---

## 0) PRINSIP KERAS

1. Figur dunia nyata TIDAK BOLEH muncul literal (nama asli, identitas publik, kejadian publik sebagai “fakta cerita”).
2. Semua pengaruh real-world wajib lewat PROXY.
3. Anti-idolizing: proxy tidak boleh jadi “legenda sempurna” atau pusat makna hidup Handy.
4. Jika konflik antara “ikonik” vs “manusiawi” → PILIH MANUSIAWI.
5. Jika konflik antara “proxy” vs “keluarga/inti cerita” → KELUARGA/INTI CERITA MENANG.

---

## 1) STATUS & ATURAN PAKAI

### REGISTERED

- Boleh dipakai lintas bab/fase sesuai batasan.
- Boleh punya dampak nyata, tapi tidak menggeser tema inti.

### PROPOSED

- Hanya boleh muncul MAKSIMAL 1 kali, durasi singkat, dampak kecil.
- Wajib “soft-intro” (tidak mengunci relasi/karier).
- Setelah penulis setujui → ubah jadi REGISTERED.

### ARCHIVED

- Dilarang dipakai sampai penulis mengaktifkan ulang.

## 3) RULE KHUSUS (WAJIB)

### 3A. Mentor/Tamu

- Maksimal 1–2 kalimat “insight” per kemunculan.
- Dilarang memberi “ramalan sukses”.
- Dampaknya bekerja pelan (habis adegan pun tidak perlu dibahas besar-besaran).

### 3B. Pasangan

- Wajib punya agenda/karier/masalah sendiri.
- Boleh putus–nyambung, tapi tidak jadi alat pencitraan.
- Dilarang “perfect couple”.

### 3C. Rekan Kerja (manager/partner)

- Boleh jadi panjang lintas fase, tapi tetap dicatat sejak kemunculan pertama.
- Tidak wajib masuk core, tapi wajib ada jejak kontinuitas.
