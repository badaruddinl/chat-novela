# INVENTORY & JEJAK MATERIAL

Dokumen ini mencatat ASET MATERIAL
yang MEMILIKI MAKNA NARATIF
dalam hidup tokoh utama (Handy)
dan karakter penting lain jika relevan.

Dokumen ini BUKAN daftar barang.
Ini adalah JEJAK HIDUP.

Agent WAJIB membaca dokumen ini
sebelum menulis bab baru
yang melibatkan:

- rumah
- kendaraan
- alat kerja
- properti usaha
- pelepasan / donasi / kehilangan aset

---

## PRINSIP UTAMA

1. Barang TIDAK BOLEH muncul tiba-tiba.
2. Setiap aset utama HARUS punya:
   - asal yang masuk akal
   - konteks fase hidup
   - dampak emosional atau konsekuensi
3. Aset boleh:
   - dibeli
   - diwariskan
   - diberikan
   - dijual
   - ditinggalkan
   - rusak
4. Aset yang HILANG / DILEPAS
   HARUS meninggalkan jejak naratif.

Jika ragu:
→ TUNDA kemunculan aset  
→ atau PERKECIL skalanya

---

## DEFINISI ASET (WAJIB DIPAHAMI)

ASET adalah sesuatu yang:

- dimiliki atau dirawat jangka panjang
- memengaruhi ritme hidup
- membawa tanggung jawab / beban
- muncul berulang lintas bab / fase

Contoh ASET:

- rumah / kontrakan
- motor / mobil
- alat kerja utama
- studio / camp / radio
- barang simbolik (alat musik pertama, jam, dll)

BUKAN aset:

- sepatu harian
- tas sekolah
- ponsel sementara
- latar umum (kafe, venue)

---

## FORMAT WAJIB PENCATATAN

Setiap aset dicatat dengan format berikut:

### AST-[KODE] — [NAMA ASET]

Pemilik:

- Handy / keluarga / bersama

Fase:

- FASE [x]

Asal:

- beli / hadiah / hasil kerja / warisan / kolaborasi

Status:

- aktif / dijual / dihibahkan / ditinggalkan / rusak

Makna Naratif:

- 1–2 kalimat (emosi / simbol / beban)

Konsekuensi:

- perubahan ritme hidup / tanggung jawab / konflik kecil

Catatan Kontinuitas:

- kapan mulai sering muncul
- kapan mulai menghilang (jika ada)

---

## FASE 1 — AKAR (SD)

### AST-HOME-00 — Rumah Keluarga

Pemilik:

- orang tua

Lokasi:

- Purwodadi

Status:

- dihuni

Makna Naratif:

- pusat stabilitas
- tempat belajar diam, menahan, dan mengalah

Konsekuensi:

- Handy tidak punya kontrol atas ruang
- semua keputusan bersifat keluarga

Catatan:

- BUKAN milik Handy
- selalu menjadi referensi “pulang”

---

### AST-GEAR-00 — Perlengkapan Olahraga Seadanya

Pemilik:

- keluarga

Status:

- aktif / tambal-sulam

Asal:

- dibelikan orang tua
- diperbaiki dengan lem sepatu

Makna Naratif:

- simbol usaha diam-diam keluarga
- rasa “utang kecil” yang tidak pernah diucapkan

Konsekuensi:

- Handy belajar berlatih tanpa menuntut
- prestasi selalu dibarengi rasa sungkan

---

## FASE 2 — PERGESERAN (SMP)

_(BELUM DIAKTIFKAN)_

Catatan:

- Fase ini mulai memunculkan KEINGINAN memiliki
- Belum ada aset permanen
- Jika aset muncul:
  → harus kecil
  → bersifat pinjaman / sementara

---

## FASE 3 — PEMBENTUKAN (SMA)

_(AKAN DIAKTIFKAN SAAT CERITA MENCAPAI FASE INI)_

- Handy

- FASE 3

Status:

- aktif

Makna Naratif:

Konsekuensi:

---

## PELEPASAN / PENGURANGAN ASET

Jika aset dilepas, WAJIB dicatat ulang:

### AST-[KODE] — [NAMA ASET]

Perubahan Status:

- dijual / dihibahkan / ditinggalkan

Alasan Naratif:

- (logis & emosional)

Dampak:

- (ringan / sunyi / membebaskan / meninggalkan jejak)

Catatan:

- Tidak perlu adegan besar
- Tapi TIDAK BOLEH tanpa jejak

---

## ATURAN KERAS (REKAP)

Agent DILARANG:

- memunculkan aset besar tanpa asal
- menghapus aset tanpa catatan
- menjadikan aset sebagai glorifikasi status
- “loncat kelas hidup” tanpa proses

Agent WAJIB:

- memperlakukan aset sebagai BEBAN HIDUP
- membiarkan aset mengubah ritme
- mencatat aset secara organik dari cerita

Jika ragu antara:
pamer vs proses  
→ PILIH PROSES

Jika ragu antara:
ikonik vs manusiawi  
→ PILIH MANUSIAWI
